# 布局系统

屏幕里每个容器要么按流向排列子元素，要么让子元素自己管坐标。这一页定死两种模式的数据形状、渲染规则和编辑手感。

## 两种模式

- **自由（free）**：子元素各自带 `x` / `y`，相对父容器左上角。用户拖出来的画板、随手摆的元素都是这种。
- **流向（stack）**：容器决定排列，子元素只排顺序，不存坐标。轴、间距、内边距、两轴对齐都由容器说了算。

模式挂在容器上，字段是 `layout`：`null` 表示自由，有值表示流向。画板和图层都能当容器，所以两者都有这个字段。

```
StackLayout
  direction: 'row' | 'column'
  gap: number                     # 子元素之间
  padding: { top, right, bottom, left }
  align: 'start' | 'center' | 'end' | 'stretch'    # 交叉轴
  justify: 'start' | 'center' | 'end' | 'between'  # 主轴
```

## 尺寸三态

每个图层的宽和高各有一个模式：

| 模式 | 含义 | 渲染 |
|---|---|---|
| `fixed` | 用存下来的数值 | 像素 |
| `hug` | 贴着内容 | `auto` |
| `fill` | 占满容器剩下的空间 | 主轴 `flex: 1 1 0`，交叉轴 `align-self: stretch` |

文字默认「自动 × 自动」，图形默认「固定 × 固定」。画板尺寸永远固定，没有三态。

`width` / `height` 两个数字只在 `fixed` 时被渲染读取。其余模式下它们是最近一次量到的值，给人看数、给交接用，不参与布局。

## 渲染规则

编辑器就是浏览器，不自己算几何：

- 流向容器 → `display: flex` + `flex-direction` / `gap` / `padding` / `align-items` / `justify-content`。
- 流向里的子元素 → 按尺寸三态换成 `width`、`height`、`flex`、`align-self`。
- 自由容器里的子元素 → `position: absolute` + `left` / `top`。
- 容器都裁切内容（`overflow: hidden`），圆角因此也裁到子元素。

嵌套没有层数限制：一个流向容器里可以放另一个流向容器，也可以放自由容器。

## 编辑规则

- **自由容器里**：拖动就是改坐标，带磁吸和参考线。
- **流向容器里**：拖动就是换位置。拖到哪个兄弟前面，就在插入线标出的地方落下；拖到容器外、落进另一个容器，就是换父级。拖动时不改坐标，所以不会出现「拖了但弹回去」。
- **落点只认流向容器和画板**：自由容器不接落点，否则把元素拖到一个文字上就会嵌进文字里。要改变自由容器里面的东西的位置，先把它切开。
- **新建图层**：用图形或文字工具点进一个流向容器，就追加到它的末尾；点在自由区域，就按坐标插进最近的画板或画布根。
- **改模式**：属性栏「布局」第一排三个按钮切换自由 / 竖向 / 横向。切成自由时子元素按顺序重新给一组坐标，不留在原地。

## 和交接的关系

这个模型就是 flexbox 的薄壳：流向容器对一条 `display: flex` 规则，尺寸三态对应 `flex` 与 `align-self`，固定尺寸对应像素。交接包里每一屏的参考 HTML 直接由它生成，不需要再猜原始设计意图。
