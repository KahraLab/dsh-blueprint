# 高保真视觉系统

> 「好看」要能被检查和验收，不能只靠感觉。这份文档定四件事：样式能不能写死、令牌覆盖到哪、生成后怎么查、什么算达标。

## 一句话

样式只从设计令牌来；写死的值允许，但必须标成特例；生成后分两级检查，硬错误拦、软问题标；达标与否看一份能勾的清单。

## 一、样式只从令牌来

每个图层的每个样式属性，都映射到一个令牌路径：

| 样式 | 令牌组 | 例子 |
|---|---|---|
| 文字颜色、背景、边框色 | `color` | `color.ink`、`color.canvas` |
| 字体、字号、字重、行高、字距 | `type` | `type.body`、`type.title` |
| 内外边距、间隙 | `space` | `space.md` |
| 圆角 | `radius` | `radius.md` |
| 阴影 | `shadow` | `shadow.sm` |
| 动效时长与曲线 | `motion` | `motion.fast` |
| 边框宽度与线型 | `border` | `border.thin`、`border.none` |
| 图标尺寸 | `icon` | `icon.sm` |

数字不写在图层上，写在令牌里。图层只存路径。

## 二、令牌覆盖范围

v1 覆盖八组：颜色、字体组合、间距、圆角、阴影、动效、边框、图标尺寸。

不进 v1 的三样，各有理由：

- **透明度**：用颜色的 alpha 通道表达（`oklch(... / 50%)`），不单列一组。
- **层级（z-index）**：由布局系统按 DOM 顺序和层叠上下文决定，不该变成人肉调的数字。
- **栅格列数**：响应式整体后置，v1 只做单一目标宽度。

## 三、写死的值：允许，但要标记

真实设计总有特例：品牌 logo 有固定尺寸、异形布局要靠负边距、某个插画就是不能缩放。完全禁止会把工具变成枷锁。

规则：

- 图层属性可以存字面值，但必须带 `literal: true` 和一句理由。
- 界面里这类属性显示成不同颜色，并在检查面板里单独列一栏。
- 点一下能给替换建议：最接近的令牌值是什么，换过去视觉差多少。
- 没有写理由的字面值，算硬错误。

字面值不是二等公民，但它必须是有意识的决定，不是偷懒的结果。

## 四、生成后检查：分两级

**硬错误，直接拦，不让人存：**

- 引用了不存在的令牌。
- 令牌之间互相引用成环。
- 对比度不达标：正文文字 4.5:1，大字（18px 以上或 14px 粗体）3:1，非文字元素（图标、边框）3:1。
- 字面值没有理由。
- 组件引用的令牌断链。

**软问题，只标不拦：**

- 字号层级超过四级。
- 一屏出现两个以上主按钮。
- 间距不在阶梯上（已标特例的豁免）。
- 同类元素的圆角不一致。
- 定义了但从没被用过的令牌。
- 颜色种类过多（超过令牌定义的数量）。

软问题不拦是因为它们需要判断。比如落地页可能真的需要两个主按钮，那是设计决定，不是错误。

检查结果放在一个面板里，每条能点，点了跳到对应图层。不弹窗、不打断。

## 五、达标的清单

这份清单同时用于两件事：给 AI 的自检，和人的验收。

```markdown
- [ ] 所有图层样式来自令牌，或已标记为特例并写明理由
- [ ] 对比度：正文 4.5:1、大字 3:1、非文字元素 3:1
- [ ] 字号层级不超过四级
- [ ] 一屏最多一个主按钮
- [ ] 同类元素圆角一致
- [ ] 没有断链或成环的令牌引用
- [ ] 没有无理由的字面值
- [ ] 每屏该有的状态齐全（默认 / 空 / 加载 / 错误）
```

清单里的每一条都能被程序判断，不写「风格统一」「看着舒服」这种没法验的话。

## 六、渲染一致性

编辑器和导出的 HTML 用同一份 CSS 文本，不是两套各写一遍。验证方式是内容哈希相等，不靠肉眼比对。

令牌变量挂在 `[data-bp-dl]` 作用域，不写 `:root`。独立的参考实现（`handoff/screens/` 里的单文件 HTML）是另一回事，它自己就是一份完整文档，可以在文件内用 `:root`。

## 七、AI 怎么参与

- 模型生成和修改时，只允许输出令牌路径。要写字面值必须显式声明并给理由，否则补丁被拒绝。
- 每次模型改完，自动跑一遍检查。硬错误把结果退回给模型，让它自己修；修不好再报给人。
- 软问题不退回，攒在面板里，人自己看。

这样模型不需要理解「什么是美」，它只需要不违反能被检查的规则。

## 八、不做什么

- 不做渐变网格、混合模式、滤镜链。v1 的视觉上限是「干净、有层次」，不是「绚丽」。
- 不做暗色模式。设计语言是一套，暗色作为独立的一套语言，以后再说。
- 不做响应式栅格。v1 只对一种目标宽度负责。
