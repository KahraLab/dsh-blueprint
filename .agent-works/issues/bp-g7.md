## Question

把 MVP 切成可交付的里程碑，每段都要有能验收的产出：

- **M0**：插件能装上、能占整页、渲染一个写死的设计文档（证明宿主链路通）。
- **M1**：prompt → 生成第一版；模型 patch → 画布更新。
- **M2**：点选 + 直接操作（拖拽/改字/属性面板/图层树）。
- **M3**：设计 token（面板 + 全局生效）。
- **M4**：流程层（屏幕 + 转移 + 状态 + 总览）。
- **M5**：导出 + 版本历史 + 交接。

要回答：每个里程碑的验收标准（怎么算过了）；哪些是「必须有」哪些「可砍」；M0 到 M1 中间最大的未知是什么；整体工期粗估（人日）。

产出：里程碑表 + 每段验收清单 + 砍单优先级。
