## Question

典型入口一直缺失：用户打开 DSH，从左侧栏点「蓝图」之后看到什么，提示词发出去以后算会话还是算蓝图，蓝图在哪里管理，创建文件后编辑器怎么出现。原来的规格只写了「打开右侧栏 → 画廊 → 新建」，没有回答这条真实起点。

要回答：

- 左侧栏、设计入口页、Dashboard、右侧编辑器各自负责什么；
- 发送第一条提示词时创建什么、归到哪里；
- 蓝图文件何时创建，创建后编辑器在哪里打开；
- 编辑器怎样标明自己正在看哪份蓝图。

## Resolution

2026-10-30 定稿。

- **只做两个蓝图页面**：设计入口页和蓝图 Dashboard，都在 DSH 中央主区域。没有单独的「蓝图工作台」主界面。
- **左侧「蓝图」进设计入口页。** 页面中央是提示词输入，选一个已有工作区（默认最近使用的目录），输入框底部、工作区选择器右边是「项目蓝图库」。工作区选择器按 DSH 原生行为列出已有目录、标出当前项，并可从底部添加工作区；新目录注册后直接进左侧工作区列表。
- **发送提示词只启动普通 Agent 会话。** 会话归属所选工作区，正常出现在 DSH 左侧的工作区会话列表里；这一步不创建蓝图，也不要求已经有蓝图。
- **「项目蓝图库」打开 Dashboard。** Dashboard 展示当前工作区的全部蓝图，负责查看和管理；它不负责开始会话。
- **创建蓝图是显式动作。** 它等于创建 `<id>.blueprint.json`，创建后打开右侧蓝图编辑器预览这份文件。创建入口可以是 Dashboard 的「新建蓝图」，也可以是会话里让 AI 创建蓝图。
- **没有专用会话类型。** 蓝图通过 DSH 普通会话创建和修改，不造新的会话形态。
- **编辑器标明文件身份。** 左栏顶部显示蓝图展示名（默认「未命名蓝图」），下面一行用等宽字体的灰色小字显示 id（蓝图目录名），留出间距后再显示「层级」。名字可改，id 创建后不变。
- **每个会话记住自己的蓝图。** 一个会话打开或创建了哪份蓝图，属于会话级界面状态；重开这个会话时右侧回到那份蓝图，不能被别的会话改掉的全局指针带跑。
- **右侧编辑器保留。** 它仍在会话右侧栏，和内置浏览器、终端同列；中央页面不替代它。

- **Dashboard 打开蓝图借用普通会话。** 优先复用当前主视图所在工作区的会话，其次是工作区里最近更新的会话；都没有时才创建一个空白普通会话。随后打开右侧编辑器，不在中央另造一个编辑器页面。
