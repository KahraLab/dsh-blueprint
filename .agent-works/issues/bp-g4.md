## Question

屏幕 + 转移 + 状态的数据与交互怎么定？

- **创建转移**：从热区拉线、在总览里连线、还是聊天说「点这里去详情页」？
- **条件与分支**：真实流程有分支（有权限/无权限、有数据/空）。第一版支持条件分支吗，还是只做线性 happy path？
- **总览视图**：只读缩略图 + 连线，还是可编辑的节点图？放大缩小、自动布局怎么处理。
- **两种模式**：编辑模式 vs 播放（走查）模式怎么切换；走查时能不能边点边评论。
- **AI 生成流程**：「生成一个注册到下单的完整流程」应该产出什么——一组屏幕 + 转移 + 每屏状态，还是一条可读的流程描述。

产出：流程层的数据结构 + 交互规格 + 一个「电商下单流程」的示例数据。
