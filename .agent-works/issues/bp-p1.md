## Question

工作台活在右侧边栏里（和内置浏览器、终端同列），宽度有限。用一份静态 HTML 把这种受限宽度下的信息架构摆出来，回答：

1. **一屏怎么排**：画布、图层树、令牌面板、流程总览，在窄栏里怎么共存。全部挤进来会看不清，切成几页又会来回跳。
2. **要不要临时放大**：侧边栏可以手动拖宽，但宽到一定程度对话就被挤没了。是提供一个「放大到主区域」的临时模式，还是让用户自己拖。
3. **点选元素写评论**怎么发生：选中元素时浮出输入框，还是先选中再在固定位置写；评论提交后去哪里——进对话、存文档、还是两者。
4. **和对话的分工**：什么话在评论里说（「这个按钮太大了」），什么话在对话里说（「整体换个方向」）。

要回答的是布局与交互，不是视觉设计。

产出：`prototype/ia-shell.html`（浏览器直接打开，不依赖构建）+ 一页说明，写清楚为什么这样排、放弃了哪些排法。
